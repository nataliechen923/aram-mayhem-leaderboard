ARAM Mayhem Collector

Reads your group's 5 PlayARAM profiles in your own browser, exactly like you opening them yourself, and sends the games to the leaderboard. With a token saved (see Options below), one click syncs it by itself; without one, it downloads one file instead. It makes no requests to PlayARAM of its own — the only request it ever makes itself is the one that sends the games to GitHub.

    Runs only on playaram.gg profile pages. If a "verify you are human" check appears, it stops and waits for you — it never tries to solve it. Extension options — add a GitHub token there to sync with one click, no dragging.
