The token is saved only in this browser, in the extension's own storage. It is never sent anywhere except GitHub, and never shown to anyone.
Keep it secret, like a password. This token can write to this one repo only. Never share it, and never paste it in a chat, an email, or anywhere else. You can take it away any time: GitHub → your photo → Settings → Developer settings → Personal access tokens — delete it there, and the extension just goes back to downloading the file instead.

Test checks the token can see the repo. The first sync proves it can write to it. Tokens expire — if you set it for a year, paste a fresh one when GitHub reminds you, and everything carries on.
