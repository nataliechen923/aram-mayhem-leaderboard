How the ranking is fair

No single stat decides your rank. Every game is graded against players in the same role — tanks vs tanks, carries vs carries — then adjusted for the champion played.

Score = 55% average grade + 20% middle grade + 10% lowest grade + 15% win rate. Each game is scored 70% against your role and 30% against the same champion. Kills, deaths and assists are just 1 of 7 things that count; win rate is only 15% of the score.

When You Stack

Stacking means playing in the same game together. Each row shows how the group did when that many of the group were in the game — alone, in small groups, or all five together.

How the Rating Works

Where this data comes from: the numbers on this page right now are a Nov 8, 2026 snapshot copied from the original page (bboyisk.github.io/aram-mayhem-assessment), which sourced its per-player history from PlayARAM and its population baselines from MayhemMeta. This page never contacts PlayARAM — nothing here was scraped from it after it blocked us. Future updates come from each player's PlayARAM profile, fetched once a day by GitHub Actions (no Riot API key needed — Riot's API does not reliably serve ARAM Mayhem), with a manual CSV export as backup. PlayARAM's match list shows result, champion, KDA, CS and skillshots dodged, but not damage, so Damage stays blank on PlayARAM games — a missing field is skipped, never scored as 0. Subscores, recent-20 and top/worst champions stay blank until that first update — no values were invented to fill them.
